# SETTY 도메인 용어사전

- 상태: **초기 승인 후보**
- 목적: 화면·기획·운영·코드·API가 같은 개념을 사용하도록 경계를 정한다.

## 팀 확인 필요

- `견적 신청하기`: 예상 견적 문자 링크의 현재 후보 문구다. 도메인에서는 `배차 요청`으로 부르며 홈의 `배차 요청하기`와 문구를 통일할지 확인한다.
- `배송 신청`, `배송 견적 요청`: 과거 문서에서 현재의 `배차 요청`과 같은 의미로 사용됐다. 최신 실행 문서에서는 `배차 요청`으로 통일한다.
- `유효 견적 요청`: 현재 제출 형식 기준이지만 동일 사용자·물품 중복 판단을 실제 데이터 후 재검토한다.

DB 설계가 끝나면 실제 테이블·컬럼·타입·제약·민감도는 별도 데이터 사전으로 작성한다.
