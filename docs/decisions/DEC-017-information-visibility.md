# DEC-017 역할별 정보 노출

- 상태: **합의**
- 결정일: 2026-08-05
- 참여자: 캐리, 스마일, 밀란, 타스, 코코

## 문제와 사실

위치 중개 가치를 지키면서 운영자와 운송자가 배송에 필요한 정보를 확인해야 한다.

## 선택지

- 상대 정보 미노출
- 최소 식별 정보 노출
- 단계별 공개

## 결정

- 구매자는 판매자 입력 완료 여부만 확인한다.
- 판매자는 구매자의 개인정보를 확인하지 않는다.
- 운영자는 서비스 처리에 필요한 양쪽 정보를 확인하지만 외부 공유하지 않는다.
- 운송자는 픽업·배송에 필요한 양쪽 이름·연락처·상세주소와 픽업 시간을 받는다.
- 운영 메모와 분석 정보는 운송자에게 제공하지 않는다.

## 영향·검증

역할별 API 응답과 화면을 분리하고 미인증·다른 역할 접근을 테스트한다. “위치가 전혀 노출되지 않는다”가 아니라 “당사자 사이의 직접 노출을 줄인다”고 설명한다.

- 검증 담당: 타스
- 개발 차단: 가상 데이터 기반 두 흐름 연결은 차단하지 않음
- 사용자 공개 차단: 역할별 응답·권한 검증 전 실제 배송 흐름 공개 불가
- 재검토: 실제 운송 수행에 추가 정보가 필요하거나 과다 노출이 발견될 때

## 연결·대체

- 관련 문서: `docs/product/product-brief.md`, `user-operation-flow.md`, `mvp-scope.md`
- 관련 카드: 역할별 API 응답, 운영자 화면, 판매자 링크, 개인정보 QA
- 사용자 영향: 상대방 상세정보 대신 처리 상태만 확인
- 운영 영향: 당사자 조율이 운영자에게 집중됨
- 기술 영향: 역할별 응답·접근 테스트 필요
- 대체: DEC-004의 모호한 “노출 범위를 줄임” 표현을 구체화
