# DEC-021 운송 채널과 실제 접수 조건

- 상태: **검증 필요**
- 결정일: 2026-08-05
- 참여자: 캐리, 스마일, 밀란, 타스, 코코

## 현재 방향

- 주 운송 채널은 카카오퀵 하나를 사용한다.
- 대체 채널은 첫 MVP에 두지 않는다.
- 운영자가 물품과 차량을 판단하고 예상·최종 가격을 직접 조회한다.
- 착불과 포장·분해·상하차는 실제 채널에서 가능한 범위만 안내한다.

## 검토한 선택지

- 검증된 단일 채널만 사용
- 주 채널과 대체 채널을 함께 검증
- 운송 조건 확인 전 견적 실험만 공개

## 확정하지 않은 외부 사실

제3자 대신 접수, 계정 사용, 차량별 규격, 현금·계좌이체 착불, 추가 비용, 포장·분해·상하차 옵션은 공식 조건 또는 실제 접수 화면으로 확인되지 않았다. 워크북의 경험 기반 문구를 사용자 보장으로 사용하지 않는다.

## 검증 계획

- 담당: 캐리
- 기한: 배차 요청 공개 전
- 방법: 공식 약관·도움말·실제 계정 화면 확인, 가상 조건으로 접수 직전까지 운영 리허설, 결과 링크·캡처를 개인정보 없이 보존
- 막히는 작업: 실제 가능 안내, 최종 금액 안내, 실제 배차·배송 완료 실험
- 개발 차단: 공통 환경·가상 데이터 기능·예상 견적 저장은 차단하지 않음
- 사용자 공개 차단: 실제 배차 요청·배차 흐름은 차단
- 재검토: 채널 조건 변경, 반복 배차 실패 또는 지역 확장 시
